# Contract requests — C01

## 1. Vector spec labels are not on the wire

**File:** `packages/contracts/src/dto.ts` (`SubmissionDetailDto`), additive.
**Change:** add `readonly vectorSpec: { key: string; label: string; immovable: boolean; appetiteFactor: boolean }[]`
(or the full `VectorSpec`), filled by A12 from the active spec.
**Why:** `VectorView` needs key/label/immovable per component; `FeatureVector`
has only `x/t/m`. Optionally also `scaled` values, so panel (h) can show them.
**Workaround in place:** `apps/console/src/api/client.ts` holds a private,
display-only copy of `packages/engine/vectors/{commercial,tenant}.json` v1.0.0
key/label/immovable/appetiteFactor columns; `scaled` is `null`. Remove the copy
once the DTO carries it.
