# V06 contract request — export the extraction check from the verify barrel

- **File:** `packages/verify/src/index.ts` (frozen barrel).
- **Change (additive, one line):** `export * from './replies/index.js';`
- **Why:** `runExtractionCheck`, `scoreExtraction`, `BROKER_REPLIES` and `EXTRACTION_GATE` are
  needed by whoever writes the extraction row of `VERIFICATION.md` (the LLM CLI / report units).
  The package `exports` map only exposes `.`, so a consumer outside `packages/verify` cannot reach
  `src/replies` without this line.
- **Workaround in place:** in-package consumers import `./replies/index.js` directly. No name in
  `replies/` collides with an existing barrel export.
