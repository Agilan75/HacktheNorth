# A04 request — an offline test path

**File:** `docs/contracts/UNITS.json` / `docs/contracts/OWNERSHIP.json`, unit A04.

**Change:** add `apps/api/src/llm/calls/narrate.test.ts` (or `verify-fix.test.ts`) to A04's `owns`.

**Why:** A04 owns only `narrate.live.test.ts`, which the default `vitest` run excludes. The 18 offline fake-provider tests for `narrateCall` and `verifyFixCall` (number/recommendation survival, conservative verify-fix degrade, confidence clamp) therefore only run under `RUN_LIVE=1`.

**Workaround in place:** the offline tests sit in `narrate.live.test.ts` ahead of a `describe.skipIf` live block. Run them offline with
`GEMINI_API_KEY= RUN_LIVE=1 VITEST_MAX_WORKERS=1 npx vitest run apps/api/src/llm/calls/narrate.live.test.ts --project api`.
At the checkpoint, moving the two offline `describe` blocks (and the `vi.mock('../generate-json')` shim, which can then be dropped since A02 is implemented) into `narrate.test.ts` is a pure cut-and-paste.
