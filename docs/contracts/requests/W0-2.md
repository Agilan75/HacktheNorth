# Contract requests from W0-2 (Engine contracts)

W0-2 owns `packages/engine/src/**` and `packages/engine/vectors/*.json` only.
W0-1 owns `packages/engine/package.json` and `packages/engine/tsconfig.json`.
Three things the engine package needs from them:

1. **`zod` must be a dependency of `packages/engine`.** `src/schemas.ts` imports
   it directly (`import { z } from 'zod'`). The BUILD_PLAN dependency list
   already pins `zod ^4`; this is only a note that the engine, not just the
   contracts package, needs it. Nothing else is imported from outside the
   package — no LLM SDK, no `apps/*`, no Federato types.

2. **The package must ship its data directories.** `vectors/`, and later
   `rules/`, `rating/` and `questions/`, sit beside `src/` and are read by
   `data.ts` at runtime through `import.meta.url`. If `package.json` carries a
   `files` array it must include them; if `tsconfig.json` sets `rootDir`, it
   must be `src` so the JSON never lands in the build output path.

3. **Module resolution.** Every internal import in `packages/engine/src` is a
   relative specifier written with an explicit `.js` extension
   (`./types.js`). That resolves under both `"moduleResolution": "Bundler"` and
   `"NodeNext"`, so either setting in `tsconfig.base.json` works.

No change to any file owned by another unit is required. Nothing is blocked.
