# Contract requests — W0-3 (Federato, DTO and API contracts)

Three additive changes to files W0-3 does not own. Each has a local workaround
already in place; nothing is blocked.

---

## 1. `packages/federato/tsconfig.json` does not include `fixtures/`

**Owner:** W0-1.

**The file:** `packages/federato/tsconfig.json` has `"rootDir": "src"` and
`"include": ["src/**/*.ts", "src/**/*.json"]`.

**The problem:** `packages/federato/fixtures/mini-snapshot.ts` — which W0-3 owns
and which AGENTS.md §5 names as the first fallback for every offline test — sits
outside `rootDir`, so `tsc -b` never typechecks it. Vitest resolves and runs it
fine, so tests work; it is the typecheck that has the blind spot, and a fixture
that drifts out of shape would only surface as a test failure in some other
unit.

**The change asked for (additive):**

```jsonc
{
  "compilerOptions": { "rootDir": "." , "outDir": "dist" },
  "include": ["src/**/*.ts", "src/**/*.json", "fixtures/**/*.ts"]
}
```

Widening `rootDir` to `.` keeps every emitted path stable relative to the new
root and is the smallest change that brings the fixture under the build.

**Workaround in place:** the fixture imports `../src/types` relatively and is
written to typecheck under the same settings; it is simply not part of the
project build until this lands.

## 2. `packages/contracts/tsconfig.json` and the `format.test.ts` file

**Owner:** W0-1.

`packages/contracts/src/format.test.ts` is listed in
`docs/contracts/OWNERSHIP.json` as W0-3's and has been written. It is inside
`src/**`, so it *is* part of the contracts project build. That is fine today
(vitest is a dev dependency at the root and `describe`/`it`/`expect` are
imported explicitly, not globals), but if `tsc -b` is ever run in an
environment without `vitest` resolvable, this one file will fail to typecheck.

**The change asked for (optional):** add `"exclude": ["src/**/*.test.ts"]` to
`packages/contracts/tsconfig.json`, or leave it as is if vitest is always
installed. No workaround is needed; this is a note, not a blocker.

---

## 3. No test files were created for other units' modules

**Not a request — a statement of what W0-3 deliberately did not do.**

`docs/contracts/OWNERSHIP.json` assigns several `*.test.ts` and `*.live.test.ts`
paths to Run 1 units (F02, A02–A06, …). W0-3 created **module** stubs for every
non-test path in `packages/federato`, `packages/contracts` and `apps/api`, but
created **no** test files it does not own, matching W0-4.11. Those units will
have to create their own test files. If the "Run 1 never creates a file" rule is
meant to cover test files too, they need to be seeded at CP0 by the human;
W0-3 did not do it because an empty or throwing test file fails `vitest` at CP0.
