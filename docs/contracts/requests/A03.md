# Contract request — A03

**File:** `docs/contracts/OWNERSHIP.json` / `docs/contracts/UNITS.json` (A03 `owns`)

**Change:** add `apps/api/src/llm/calls/observe.test.ts` (and optionally `relate.test.ts`) to A03's owned paths.

**Why:** A03's only owned test path is `observe.live.test.ts`, which `vitest.config.ts` excludes unless `RUN_LIVE=1`. The offline fake-provider tests for `observeCall` and `relateCall` (11 cases) therefore never run in the default suite.

**Workaround used:** the offline cases live in `observe.live.test.ts` under `describe('observeCall (fake provider)')` and `describe('relateCall (fake provider)')`; the live block is `describe.skipIf(!LIVE)`. At the checkpoint, move those two offline `describe` blocks verbatim into `observe.test.ts` (imports unchanged) so they run offline by default.
