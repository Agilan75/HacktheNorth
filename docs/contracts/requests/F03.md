# F03 contract request — let package tests type-check against `fixtures/`

**File:** `packages/federato/tsconfig.json` (frozen).

**Problem:** `rootDir: "src"` plus `include: ["src/**/*.ts"]` means any `src/**/*.test.ts` that does
`import ... from '../../fixtures/mini-snapshot'` fails `tsc --noEmit -p packages/federato` with
TS6059 / TS6307. AGENTS.md §5 tells every federato unit to test against that fixture, so every one
of them hits this.

**Requested change (either):**
1. Exclude tests from the build project: add `"exclude": ["src/**/*.test.ts"]` and type-check tests
   through a separate `tsconfig.test.json` with no `rootDir` that includes `src` and `fixtures`; or
2. Drop `rootDir` to `"."` and add `"fixtures/**/*.ts"` to `include` (changes `dist/` layout — check
   the package `exports` first).

**Workaround used:** `packages/federato/src/mock/where.test.ts` loads the fixture with
`await import(FIXTURE_PATH)` where `FIXTURE_PATH: string` is non-literal, and casts the module to
the three arrays it uses. Once the tsconfig is fixed, replace it with a normal static import.
