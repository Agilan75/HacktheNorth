# E16 — runEngine composer + synthetic fixtures: decisions

## 1. merge (4) runs before rollup (3)
PRD 6.3 numbers rollup before merge, but merge can write rollup-feeding paths
(`buildings.*.yearBuilt`, `locations.*`, `history.*`), and `merge.ts` itself says
"the composer must re-run stage 3 before vectorizing". Running merge once and
then rollup once gives the same answer as rollup → merge → rollup with one fewer
pass. The rollup is attached to `canonical.rollup`, which is what `vectorize`
reads. Rejected: rollup before merge only (answers would never move the score).

## 2. Peers run inside runEngine when `peerVectors` is non-empty
`price` takes a `PeerResult` for the expected-loss complement, and
`EngineInput.peerVectors` says "Empty disables peers". So: non-empty → `peers()`
runs before `price`; empty/absent → `peers: null`. `rank` stays outside.

## 3. flip before verdict
`verdict(evaluated, contradictions, flip)` reports `distanceToAppetite` from the
flip (V-9), so flip (10) is computed first and passed in.

## 4. `explanation: null`
The PRD 7.7 template is `packages/federato/src/explain/template.ts` (F12), which
consumes the whole `EngineResult`. The engine never writes prose; the API fills
the explanation. Rejected: a second template inside the engine (two sources of
wording that could drift).

## 5. Quality index uses `config.qualityWeights ?? QUALITY_WEIGHTS`
Computed via E10's `qualityIndex` over the otherwise-complete result.

## 6. `interpretations` = `evaluate.interpretationsApplied`, de-duplicated by id
Only interpretations that actually applied, not the rulebook's full list.

## 7. Synthetic fixtures
B1–B12 from INTERPRETATIONS §8 built as real buildings/claims (not a prebuilt
rollup), so they exercise stage 3. Every building is sprinklered with protection
class 3 so the extension rules fire Target only and never add a REFER that §8
does not expect. Extra cases: SYN-PERFECT (100, zero claims = known $0),
SYN-I3 (fire resistive counts acceptable), SYN-I4 (both window edges inclusive),
SYN-EMPTY (claims never fetched → loss missing; only line of business known,
score 15, completeness 1/9, REFER), SYN-EXTREME (score 15, DOES_NOT_FIT).
The received date is pinned so results do not depend on `asOf`.

## 8. Test file
`src/runEngine.test.ts` is the colocated test (same convention every other
Run 1 engine unit followed for `stages/*.test.ts`). It uses an inline
commercial rating table because `rating/commercial.json` is E17's and not yet
frozen, and reads JSON with `readFileSync` because `parse*` (E13) is still a stub.
