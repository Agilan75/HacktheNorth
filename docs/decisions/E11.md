# E11 — sweep geometry decisions

| # | Decision | Reason | Rejected alternative |
|---|---|---|---|
| 1 | A frame covers the half-open arc `[bearing - fov/2, bearing + fov/2)`; a panel counts when that arc overlaps it by more than 1e-9°. FOV <= 0 or non-finite touches only the bearing's own panel; FOV >= 360 touches all 36. | Half-open intervals mean a frame edge that lands exactly on a panel boundary does not claim the next panel, so 27 frames centred in panels 0..26 at FOV 10 give exactly 75%. | Closed intervals, which would over-count every boundary-aligned frame. |
| 2 | `coveragePct = coveredPanels * 100 / 36`, unrounded; `sufficient = coveragePct >= MIN_COVERAGE_PCT` (27/36 = 75 exactly passes). | PRD 9.3 / 11 "Finish at >= 75%". | Rounding the percentage before comparing. |
| 3 | Arc shape: `startDeg` in [0, 360); `endDeg = start + width` when that is <= 360 (a run ending at north reports 360), otherwise the normalized end (the wrap case, `start > end`). Full circle is `{0, 360, 360}`. Lists sorted by `startDeg`. | Matches the `CoverageArc` doc comment ("0..360", "startDeg may exceed endDeg when wrapping"). | Always normalizing end to [0, 360), which makes a 300..360 run read `300 → 0` as if it wrapped. |
| 4 | `largestUncoveredGap` / `largestGap` ties go to the lowest `startDeg`; no coverage returns the full circle `{0, 360, 360}`; full coverage returns null. | Deterministic, and the re-sweep hint always has an arc to name. | Returning null for zero coverage. |
| 5 | `coverage()` drops non-finite bearings; `frameCount` and `bearingsDeg` reflect only the kept, normalized bearings. | `normalizeDeg(NaN) = 0` would otherwise falsely mark panel 0 as scanned. | Counting every input bearing. |
| 6 | Radar placement uses math axes, north up: `x = r·sin θ`, `y = r·cos θ` (bearing 0 → (0, r), 90 → (r, 0)). Screen renderers flip y. Float noise below 1e-9 snaps to 0. | Bearings are clockwise from north; this is the standard compass-to-cartesian map. | Screen axes (y down) baked into the engine. |
| 7 | `placeObject(id, bearing, band)` has no label or confidence in its frozen signature, so it returns `label: 'unknown'`, `confidence: 0`; `placeObjects` overwrites both from the observation. | Signature is frozen; `PlacedObject` requires both fields. | Changing the signature. |
| 8 | HELPERS.md names `normalizeBearing`, `bearingDelta`, `arcUnion`, `coveredFraction`, `largestGap`, `withinTolerance`, `dedupeByBearing` as living here; they are added as extra exports (not in the frozen barrel, import from `sweep/geometry.js` directly). `bearingDelta` is signed clockwise in (-180, 180]; `withinTolerance` is inclusive (+ANGLE_TOLERANCE); `dedupeByBearing(items, tol, sameGroup?)` keeps the first item of each cluster, so callers sort by confidence first. Panel functions are implemented on top of `arcUnion` so both paths agree. | HELPERS.md is the contract for shared helpers. | Leaving HELPERS.md names unimplemented. |
| 9 | `normalizeBearing` adds `+ 0` to `util/math.normalizeDeg`, which returns `-0` for inputs like -360. | `toEqual` and `Object.is` distinguish -0; bearings should never be -0. | Editing util/math.ts (not owned). |
