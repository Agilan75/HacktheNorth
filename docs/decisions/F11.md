# F11 — planner run + high-scorer follow-up

Owns `packages/federato/src/planner/run.ts` (+ colocated `run.test.ts`).

## D1 — The schema fetch is not a trace entry
`getSchema()` is not a query and `TraceStart` requires a `QueryPayload`; faking one
would put a payload in "How the agent got here" that was never sent. The `schema`
pass stays unused. A failed `getSchema()` throws (no schema, no plan).

## D2 — Query errors never throw
A failed triage/deep/no-policy/follow-up query is recorded in the trace
(`outcome: 'error'`, parsed `[CODE]`) and pushed to `warnings`; the run continues.
A failed deep pass sends every survivor down the no-policy pass so it resolves to
REFER rather than vanishing. Rejected: throwing — it loses the trace that shows why.

## D3 — Adaptation loop
Each empty result asks F10's `nextAdaptation` for the next step; each retry is a
separate `adapt_retry` entry whose `adaptedFrom` points at the query it replaced,
with F10's `why` as a note. When nothing is left the empty entry gets a note.
Array paths for the `$elemMatch` swap come from the schema: every `isArray` field
reachable from the root within 4 graph hops.
Consequence: the verified deep pass has a single `where` condition that does not
cross an array, so an empty deep pass is NOT widened (F10 D2) — it stands, noted.

## D4 — Widened retries never leak accounts
After a `drop_narrowest_filter` retry the no-policy and follow-up rows are filtered
back to the external ids the plan asked for.

## D5 — OVER_DECLINED_NOTE on the deep pass (per F10 D5)
Always noted on the first deep-pass entry.

## D6 — runFollowUps patches bundles, continues the trace
Only accounts whose bundle has a hydrated `Policy` are followed up (coverages,
endorsements and producer hang off Policy); others are named in a warning. Follow-up
entries are renumbered to continue the run's sequence (`q-003`…), `adaptedFrom`
remapped. Rows are appended (sorted by id) to that bundle's `records.Policy`, matching
`toBundles` layout; every bundle's `queryTraceIds` gains the new ids. Returns the
input object unchanged when `skipFollowUps` is set or nothing qualifies.
`counts.followUps` = number of external ids followed up.

## D7 — Warnings
Page-limit truncation (total > returned), unmapped fields (one summary line),
schema-assist failure (falls back to deterministic locate) and dropped-condition
deep passes are warnings.
