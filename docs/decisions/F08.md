# F08 — planner collect + locate: decisions

1. **Collect emits base canonical fields, not rollup outputs.** A rule that reads
   `rollup.totalTiv` (via component `totalTiv`) yields `buildings[].tiv`; the
   rule's own read path is kept in `TraceRuleNeed.canonicalPath`. A private table
   maps each `Rollup` key to the canonical inputs engine rollup reads. Rejected:
   emitting `rollup.*` paths — none can ever exist in the schema, so every one
   would be "unmapped".
2. **Collect also walks every spec component** (`ruleId: vector:<key>`), because
   completeness counts them even if no rule tests them. Rating-table needs use
   `ruleId: rating:<column>`; a rating table for the other line is ignored.
   `buildings[0].x` normalizes to `buildings[].x`.
3. **componentKey / factor** on a NeededField are set only when all contributing
   needs agree on one value; otherwise null (e.g. `buildings[].tiv`).
4. **Root choice.** Policy first, then Submission (the deep and no-policy roots).
   Among graph paths to the owning resource: per-item canonical paths (`[]`)
   prefer an array-crossing route (so `locations[].state` goes through
   `exposure_units.location`, not `insured.hq`), then fewer hops, then dot-path.
5. **Graph step confidence.** Unique normalized-name match inside the resource
   the canonical path names (`buildings[]` -> Building), or unique in the whole
   schema when the path names no resource (`history[]`): 0.85, accepted.
   Ambiguous or found only outside the named resource: 0.6, a visible guess.
   So `buildings[].protectionClass` stays unmapped (Building has no such field in
   the live schema), with `Location.protection_class` shown as the rejected guess.
6. **Assist.** Called once, only with the names synonym + graph could not
   resolve, offering every non-reference `Resource.field` not already claimed
   (sampleValues empty: locate runs before any record query). Accepted only if
   rawPath was offered, canonicalPath was asked for, and confidence is in
   [0.8, 1]; highest confidence wins per name. A throwing assist never fails the
   planner: `assistUsed` stays false and the reason is on each unmapped field.
7. **FieldMap.** `rawPath` uses engine discover's `Resource.path` format of the
   leaf (`Building.tiv`); `note` carries the root-relative path. An unmapped name
   with no guess uses its canonical path as `rawPath`, with the reason.
8. **Test mocks F07.** `locate.test.ts` mocks `./synonyms` and `./graph` (still
   stubs at the time of writing) with a controlled table and a small BFS, so the
   test pins F08's own gate/fallback/routing behaviour.
