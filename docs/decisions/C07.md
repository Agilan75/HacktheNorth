# C07 decisions — QueryTrace + Schema panels

1. **Trace order.** QueryTrace sorts entries by `step` ascending (copy, never mutates props). Rejected: trusting API order — the view type does not promise it.
2. **Payload display.** Payload is pretty JSON inside a collapsed `<details>`; a cyclic/unserialisable payload falls back to `String(payload)` instead of crashing the page.
3. **Durations.** `< 1000 ms` prints as `N ms`, otherwise seconds at two decimals. No totals are summed across queries beyond the count of adapted queries.
4. **Mapped confidence.** `SchemaView.mapped[].score` is treated as a 0–1 confidence (PRD §7.5 step 3 threshold 0.8) and printed at two decimals, not as a percent. Rejected: `formatPercent`, which would imply a different scale than the 0.8 threshold the header tooltip cites.
5. **Schema layout.** Unmapped keys table first (PRD §10 (i) headlines them), then mapped keys, then resource coverage. `schema === null` renders an explicit empty state.
