# A10 decisions

1. **Adapter banner line reuses F05's `adapterBanner`**, called with `federatoEnv(getEnv())`, and falls back to a local line (`*** FEDERATO: SNAPSHOT ... ***` / `*** FEDERATO: LIVE API ***`) if F05 throws or returns empty. Rejected: a banners-only wording, which would duplicate F05's line.
2. **Unset `GEMINI_API_KEY` keeps the Gemini provider** (`configured: false`) rather than swapping in the fake. PRD §9.1: the API still starts and serves the seeded sweep; the fake is for tests only.
3. **`buildDeps()` keeps the `DbHandle` in a module-private variable** so `main()` can migrate, print the driver and close on shutdown without changing the frozen `Deps`/`buildDeps` signatures.
4. **`main()` auto-runs only when `index.ts` is the process entry** (`import.meta.url === pathToFileURL(argv[1])`), so importing the package in tests never opens a port.
5. **Pending stub routes and the database path are printed by `main`**, not by `startupBanner`, so the banner stays pure and testable without running every registrar.
6. **Seed sweep**: 11 observations over 15 frames at 24-degree steps; heater 48 / curtain 60 (both near) is the one `heaterNearCombustible` pair; smoke detector 0.52 and candle 0.58 go to confirmation. **Seed reply** contradicts itself on year built (1978 vs 1981) and TIV ($62M vs $64.5M), hedges construction and sprinklers, and leaves one loss amount unstated.
