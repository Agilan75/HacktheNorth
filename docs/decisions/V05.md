# V05 decisions — flip + vector invariants, engine-vs-naive comparator

1. **Only `compare.ts` imports `@retrofit/engine`.** `verify/types.ts` says only the
   comparator (V05) and the worker (V08) may import the engine. The flip and vector
   invariants need stages 6, 7, 9, 10 and 12 directly (a `NaiveInput -> result`
   probe cannot expose a flip, a vector or a peer distance), so `compare.ts` exports
   thin, verify-named adapters (`verifyEngineConfig`, `engineSubmissionForInput`,
   `engineVectorForInput`, `engineEvaluateVector`, `engineViewForInput`,
   `engineFlipForCase`, `engineApplyMoves`, `engineScaleVector`, `engineBookStats`,
   `engineVectorize`, `enginePeerDistance`, `toEngineResultView`, `engineResultView`,
   `REFERENCE_INPUTS`) and `invariants/flip.ts` / `vector.ts` import those. Additive
   exports only; no frozen signature changed. Rejected: importing the engine in the
   two invariant files (breaks the isolation rule's letter), or private copies of the
   adapters in each file (three drifting copies of the case -> engine mapping).
   `engineViewForInput` has the shape V04's `InvariantProbe` expects, so V08 can
   install it with `setInvariantProbe(engineViewForInput)`.
2. **Case -> engine mapping.** A `NaiveInput` becomes a `CanonicalSubmission` whose
   `rollup` carries the rolled-up facts, `pricing.quotedPremium` and `submissionType`
   as `self_reported` slots, then goes through the real `vectorize`. R-AGE-REFER's
   trigger reaches the engine via `rollup.oldestYearBuilt` = 1989 when
   `anyBuildingPre1990 === true`, 1990 when `false`, null when unknown.
   `CanonicalSubmission.lineOfBusiness` cannot be absent, so a null line (G-2) is
   applied on the vector (x = t = null, m = 0) after `vectorize`.
3. **Spec and rulebook are read from the frozen JSON** beside `packages/engine/src`
   via `node:fs`, through `parseVectorSpec`/`parseRulebook` when E13 has implemented
   them and as a raw cast while they still throw `NOT_IMPLEMENTED`.
4. **Scaled space uses a fixed reference book**: `computeBookStats` over the twelve
   INTERPRETATIONS §8 cases B1–B12. Deterministic, and it gives the log components a
   real min/max. `scaledComponentsInUnitRange` also checks against that book extended
   with the case itself, and against no book.
5. **Rating table** is a placeholder; `flip` already maps a pricing failure to
   `premium = null`, which no flip invariant reads.
6. **Applying a flip is checked without contradictions.** Flip is a vector-space
   stage and cannot resolve an open HIGH contradiction (V-3); it searches with none,
   so the re-run is in the same context. Rejected: re-running with the case's
   contradictions, which would flag every contradicted case as an F-6 violation.
7. **Out-of-domain raw values are skipped by the scaling check.** A `none`-scaled
   share of 1.5 passes through as 1.5 by INTERPRETATIONS §6, so a value outside the
   spec's declared `[min, max]` is a malformed input, not a scaling defect. Missing
   components must still scale to null. Rejected: flagging them, which would flood
   the 10M report with generator-hostility rather than engine bugs.
8. **Comparator fields**: `appetiteScore` and every `tierValue.<factor>` at 1e-6,
   `completeness` at 1e-9 (§7 "completeness"), `verdict` and `decidingFactorId`
   exact, `knockoutFactorIds` as an exact **set**. Non-finite numbers count as
   missing (G-1), so NaN agrees with null and nothing else.
9. **Peer symmetry** is checked through the real `peers` stage (k = 1), against the
   twelve reference vectors, at 1e-12; "zero only for identical" is judged on the
   scaled values of the components the stage actually compared.
