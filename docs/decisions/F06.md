# F06 — reference transcriptions: decisions

1. **Blank Target cell is `''`.** The four T-BLANK rows (submission type, line of business, construction type, loss value) store `target: ''`. What that means for scoring is INTERPRETATIONS.md T-BLANK's call, not this file's. Rejected: `null` (the frozen `GuidelineRow.target` is `string`).
2. **Row citation quote = the Acceptable cell.** Every row has one, and it is verbatim. Section string is `p2 "<Factor label>"`, the exact form `rules/commercial.json` already uses. Rejected: concatenating the row (not a verbatim contiguous span).
3. **PDF glyphs kept.** ASCII hyphens (`$50M-$100M`, not the PRD's en dash), curly apostrophes/quotes as extracted by pdftotext. Cell line wraps joined with one space.
4. **`resolveCitation` returns the whole section text** (a guideline row rendered as `Label: Acceptable … | Target … | Not Acceptable …`, a paragraph, a glossary definition, or a query note's quote). The checker tests `text.includes(citation.quote)`. It accepts `p2 "X"`, `page 2 X`, `"X"` or `X`, case/hyphen-insensitive; a stated page that disagrees returns `null`.
5. **Only three PDFs are transcribed** (APPETITE_GUIDELINES, GLOSSARY, QUERY_REQUEST_BODY — the unit's scope). The other three are indexed in `referenceDocuments()` with measured page counts but resolve to `null`. `PRD.md` citations also resolve to `null`: it is not a Federato document. Rejected: transcribing API_DOCUMENTATION/DATA_SCHEMA/STUDENT_PROJECT_GUIDELINES (out of scope, nothing cites them).
6. **Glossary aliases are Retrofit's**, not the PDF's: parenthesised expansions (`Application Programming Interface`) plus UI spellings (`in appetite`, `insurer`, `policies`). `lookupTerm` also strips one trailing `s` as a plural fallback.
7. **Query notes `implementation`** describes the actual planner (plan.ts as it stands) and records the one deviation: `over` is never emitted (LIVE_DATA_FACTS.md).
