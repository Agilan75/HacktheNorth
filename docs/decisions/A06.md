# A06 decisions — draft-request + extract-reply

1. **draft-request check (PRD 9.2 "every field appears, nothing else asked").** Code accepts the
   model draft only if: subject and body are non-empty, the body is at most 2000 chars, every requested
   field's label appears (lower-case, alphanumerics-only word match), every bullet line and every
   sentence ending in `?` names a requested label, there is no `$<digit>` unless the input itself had
   one, and there is no placeholder (`[..]`, `{{`, `<..>`). Anything else gets the deterministic
   `templateDraft`, which always passes the same check. Rejected: an LLM-judged check (an LLM would
   then decide what gets sent).
2. **Fallbacks.** A failed/degraded call → template for draft-request, all-`notFound` for
   extract-reply. `LlmUnavailableError` is rethrown for the route to report (same as A04's verify-fix).
   `draftRequestCall` with zero fields throws: it is a caller bug, not a draft.
3. **extract-reply value comes back as a string** (`"$2.5M"`, `"40%"`, `"1978"`), never converted by
   the model; code parses it: G-4 money (K/M/B/thousand/million/billion suffixes, commas, `$`), G-5
   years floored, G-6 percents (`"40%"` or a bare number > 1 → /100; values in [0,1] kept). Default
   ranges: year [1700, 2100], money >= 0, percent [0, 1], overridden by the spec's min/max. String
   fields with `options` must match one (case-insensitive) and return the canonical option.
4. **Quote check.** Normalised (NFKC, typographic quotes/dashes/ellipsis, whitespace, case), min 3
   chars, must be a substring of `sourceText`. A year must also appear in its own quote.
5. **PDF.** No PDF text extractor exists in the tree, so a quote not found in the pasted text is
   kept only when a PDF came with the reply, with confidence capped at **0.79** (below the 0.8 gate):
   it always goes to the underwriter to confirm. Rejected: trusting the model's PDF quote (unverified)
   and dropping PDF values (kills the loss-runs path).
6. **Self-contradicting reply.** Two different values for one field → keep the statement latest in
   the text (corrections usually follow) at confidence min(c, **0.5**). Agreeing duplicates merge at
   the weaker confidence, earliest quote.
7. **`notFound` = every requested field without a surviving value**, in request order — including
   values rejected by the checks and explicit nulls. So each requested field is in exactly one of
   `values`/`notFound`. The 0.8 acceptance gate stays with the route (it owns provenance writes).
8. Extra exports (additive, not in the barrel): `draftProblems`, `templateDraft`, `coerceValue`,
   `quoteInSource`, `validateReply`, `UNVERIFIED_QUOTE_CONFIDENCE_CAP`, `CONFLICT_CONFIDENCE_CAP`.
