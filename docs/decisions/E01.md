# E01 — decisions

Unit E01: condition operators (`packages/engine/src/util/conditions.ts`) and
field/provenance helpers (`packages/engine/src/util/fields.ts`).

Everything already fixed by `docs/contracts/INTERPRETATIONS.md` was obeyed, not
re-decided. The list below is only what that file and the PRD leave open.

## D1 — String comparison is trimmed and case-folded

`eq`, `neq`, `in`, `notin` compare two strings after `trim().toLowerCase()`.

Reason: G-7 requires state codes to match "upper-case two-letter after
trimming", G-8 requires construction types to match after lower snake_case
normalization. Folding both sides in the operator makes `" oh "`, `"OH"` and
`"oh"` one value regardless of which stage normalized first, and makes
`"Masonry_Non_Combustible"` equal `masonry_non_combustible`.

Rejected: byte-exact `===`. It would make a rule's outcome depend on whether the
normalize stage happened to case-fold a given path, which is exactly the class
of silent disagreement the differential run is meant to catch.

Note: it does **not** convert `"Masonry Non-Combustible"` (spaces/hyphens) to
snake_case. Separator normalization belongs to the normalize stage (E04), not to
a comparison operator.

## D2 — Ordering operators are numeric only

`lt`/`lte`/`gt`/`gte` return `false` unless **both** sides are finite numbers.
No lexicographic string ordering, no date-string ordering, no coercion of
`"50000"`.

Reason: G-1 makes non-finite numbers missing; there is no threshold in
INTERPRETATIONS §3 that is not numeric. A silent string comparison would make
`"9" > "10"` true.

## D3 — `exists` / `missing` never make a rule undetermined

`isUndetermined` skips conditions whose op is `exists` or `missing`, because
those ask about presence itself and always have an answer.

Rejected: treating them like any other op, which would mark every "field is
missing" rule permanently undetermined and suppress exactly the rules written to
catch missing data.

## D4 — `vectorResolver` addressing

`key` → `x[i]`, `key.t` → `t[i]`, `key.m` → the mask as a boolean. A component
with `m[i] === 0`, or a key the spec does not carry, resolves to `undefined`
(missing, per G-2 — never 0). Components are addressed by key, never by index,
per `VectorComponentSpec.key`.

Rejected: resolving an unknown key by falling through to a canonical path on the
submission. The resolver is given a vector and a spec and nothing else; a rule
that needs a rollup path gets a rollup-backed resolver from E06.

## D5 — `bestValue` tie-breaks

Order: highest `sourceConfidence`; then the source order `enrichment > answer >
sweep > self_reported` (the signature's own docstring); then the latest
`observedAt` (a value with no parseable stamp sorts as oldest); then insertion
order — comparisons are strictly-better, so an exact tie keeps the earlier
entry.

## D6 — "Materially different" in `hasCompetingValues`

Numbers: differ by more than `SCORE_TOLERANCE` (1e-6) — `approxEqual` from
`util/math.ts`. Strings: differ after trim + case-fold (same as D1). Booleans:
strict. Arrays/objects: structural, element-wise with the same rule. Every
entry is compared against the **first** entry in the slot, so any disagreement
with the incumbent value is competing.

## D7 — `readPath` unwraps `Sourced` slots

A path landing on a `Sourced<T>` returns `bestValue(slot).value`, not the array
of fields, so the caller gets the number the engine scores on. Arrays of records
(`buildings`, `locations`, `history`) are addressed by `externalId`, then `id`,
then numeric index, so `buildings.B3.yearBuilt` works as `ExternalValue`'s
docstring promises. `hazards.<key>` falls back to `hazards.present.<key>`.
An absent segment returns `undefined` (missing per G-1), never `null` or 0.

## D8 — `combinedConfidence([])` is 1

Straight from V-7: "With no deciding fields, `confidence = 1`." The product is
clamped to `[0, 1]`.

## D9 — `sourceConfidence` with a stated number

A stated finite `confidence` overrides the table for **every** source kind, not
just `sweep`, and is clamped to `[0, 1]`. A non-finite stated confidence falls
back to the table. `sweep` without a confidence falls back to
`SWEEP_FALLBACK_CONFIDENCE` (0.5), which is what that constant is for.
