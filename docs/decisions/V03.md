# V03 — decisions

## D1. Private PRNG, not V02's `createPrng`
V02 runs in parallel and `createPrng` is still a stub. V03 uses a private
mulberry32 seeded by FNV-1a of `V03-submission|seed|index`, so a submission is
replayable from `(seed, index)` and its `caseId` (`V03:<seed>:<index>`)
regardless of V02's algorithm. Rejected: importing `createPrng`, which would
make V03 untestable until V02 lands and would silently change every V03 case
if V02 ever changed its stream.

## D2. Rollup restated independently
`rollupGenerated` imports nothing from the engine. It follows INTERPRETATIONS
3.4, 3.5, I-1, I-3 and R-AGE-REFER, and copies E03's documented choices so the
two do not disagree for no reason: `totalTiv` = sum over known-TIV buildings;
`Steel Frame → steel` (plus `jm`, `noncombustible`, `masonry_noncombustible`);
unknown construction on a known-TIV building counts as "other". A share whose
denominator is 0 is `null` (the generator never produces zero-TIV buildings).
States are trimmed + upper-cased (G-7). `hasOpenHighContradiction` is always
`false` — a generated submission carries no contradictions.

## D3. `boundaries` is derived from the rolled-up value
`GeneratedSubmission` has no boundary field, so `rollupGenerated` derives it:
`at` on an exact threshold, `under`/`over` within $1 (money) or 0.01 (shares),
otherwise `random`. It also carries ambiguity markers:
`I-1:state_tie`, `I-1:multi_state`, `I-3:fire_resistive_decides`,
`R-AGE-REFER:pre1990_unknown_tiv` (and `V-3:open_high_contradiction` on the
contradiction stratum). The stratifier reads the I-1/I-3 markers because
`NaiveInput` alone cannot show them.

## D4. Stratified cases come from the generator by rejection search
Each stratified case is `rollupGenerated(generateSubmission(s, j))` for the
first `j` whose `classifyStratum` equals the stratum, with
`s = FNV(V03-stratum|seed|key|slot)`. So every case sits in exactly the
stratum it is labelled with and replays from its own seed/index. The one
overlay is `contradiction_open` (an ordinary case with the flag set, caseId
suffixed `:contradiction`).

## D5. Strata, priority and budget
28 strata (every §3 boundary, every §6.6 ambiguity, the §8 B-cases, V-3, G-2
missing data), written against a nominal 2,000: 1,720 stratified + 280
`ordinary` (cases where `classifyStratum` is `null`). Other totals scale by
largest remainder, and every stratum keeps at least one case when the total is
≥ 28. `classifyStratum` is first-match in priority order: ambiguities, then
exact thresholds, then broad buckets (minority pre-1990 refer, multi-state,
Acceptable-tier state, not-new, not-property, missing). Rejected: multi-label
strata, which would double-count cases in the agreement-rate denominator.
