# C02 decisions

1. **tokens.css generated from `cssVariableBlock()` (tokens.ts), not D01's `renderTokenStylesheet()`.**
   D01's function is still a stub in Run 1; `cssVariableBlock()` is frozen and final. The test
   asserts tokens.css contains `cssVariableBlock()` verbatim, so any token drift fails.
   Rejected: waiting on D01 (would block a Run-1 unit on a sibling).
2. **Atom styling lives as `rf-*` classes in base.css**, not inline styles, so every value is a
   `--rf-*` token and hover/media rules work. Rejected: inline styles from VERDICT_STYLES
   (no reduced-motion / cascade control).
3. **VerdictPill** renders mark (aria-hidden) + `VERDICT_STYLES[v].short` visible + full label as
   sr-only text and `title`; detail trails after ` · `. Data attrs `data-verdict`/`data-variant` for tests.
4. **CitationQuote compact** truncates via `truncateQuote(quote, 120)` from `@retrofit/contracts`,
   keeping the full quote in `title`. Source line: `document · p. N · row R` (page 0 kept).
5. **Skeleton** is `role="status"` `aria-busy`, lines clamped to 1..50, default 3, last line 60%.
6. **Card** is a `<section aria-labelledby>` with an `<h2>` title, so panels are landmark regions.
