# V06 decisions — broker reply fixtures + extraction scorer

1. **Files.** `packages/verify/src/replies/{fixtures,score,index,score.test}.ts`. The owned glob
   had no Run 0 stubs, so there was no signature to keep; the types come from the frozen
   `BrokerReplyFixture` / `ExtractionScore` in `packages/verify/src/types.ts`.
2. **`expected: null` means "must not be accepted"**, not "must be absent". The field counts as
   correct when no non-null value clears the 0.8 gate for it (absent, null, or held below 0.8).
   This matches A06, which caps conflicting values at 0.5 rather than dropping them. Rejected:
   requiring the path in `notFound`, which would penalise the A06 conflict-cap behaviour.
3. **Accuracy ignores confidence for fields with a value.** A right value at 0.6 is correct; the
   gate is measured separately by `wrongThroughGate`. Rejected: counting only gated values,
   which mixes the two numbers the PRD asks for.
4. **`wrongThroughGate` is a count** (wrong + spurious values at confidence >= 0.8), not a rate.
   The rate is `wrongThroughGate / fieldsExpected`; the frozen type holds one number and a count
   keeps it exact.
5. **Duplicates.** When a path comes back more than once, the highest-confidence value is judged
   (first on a tie).
6. **Canonical paths** used by the fixtures: `submissionType`, `pricing.quotedPremium`,
   `history.fiveYearLoss`, `buildings.<id>.{yearBuilt,tiv,constructionType,sprinklered,protectionClass}`,
   `locations.<id>.state`. The tree has no single agreed request-path vocabulary yet; the
   extractor is scored on these, and the scorer ships its own field specs (`replyFieldSpec`).
7. **Fixture judgement calls.** Renovation year is not year built (vague-06). "Roughly $8M" is not
   accepted (vague-06). "Losses have been light" is null, never 0; a stated "No losses ... $0" is 0
   (G-1). An explicit correction inside the reply (contradict-06) resolves to the corrected value;
   an unresolved conflict (contradict-01..05) is null. A 3-year loss run is null for the five-year
   figure (lossrun-05). A loss run's five-year total is the stated incurred total, never a sum the
   model computes (no LLM does arithmetic on a dollar amount).
8. **Totals.** 30 fixtures, 6 per style, 51 expected fields: 30 with a value, 21 null.
