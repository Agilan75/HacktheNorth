# A19 decisions

1. **summary.json location.** Resolved from `import.meta.url` four levels up
   (`apps/api/{src,dist}/services/` -> repo root), so source and `dist` both find
   `packages/verify/out/summary.json` without reading env or cwd.
   Rejected: `process.cwd()` — the seed script and tests run from different dirs.
2. **Missing vs corrupt summary.** ENOENT/ENOTDIR -> `verification: null` (the DTO's
   "before a run exists" case). Invalid JSON or missing DTO keys -> throw (route
   serves 500). A corrupt headline is surfaced, not hidden. Extra keys are dropped.
3. **What counts.** `total`/`byLine` count every submission row; `scored`,
   `byVerdict`, `knockedOut`, histogram and knockout factors count only rows with a
   stored `result`. Histogram bucket = `floor(score/10)` pinned to 0..9 (100 -> [9]).
4. **Knockout factors.** Count of results listing the factor (deduped per result),
   sorted count desc then AG p2 row order. Label = the guideline table's label via
   `guidelineRows()` (so `tiv` reads "TIV (Total Insured Value)").
5. **One flip away.** Non-FIT, `distanceToAppetite === 1` (V-9), flip with exactly
   one move and `verdictAfter === 'FIT'` (F-6). Ordered by stored rank (nulls last),
   then `scoreAfter` desc, then externalId. No cap; the console slices.
6. **Book adequacy.** Commercial-property results with a finite `price.adequacy`;
   median via `math.median`; underpriced = strictly `< ADEQUACY_UNDERPRICED` (0.9).
