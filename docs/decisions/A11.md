# A11 — static routes: decisions

1. **`GET /rules` `weights` = the commercial rulebook's eight appetite weights.**
   `RulesResponseDto.weights` is one flat record, but three rulebooks carry weights
   (extensions has none; tenant has 14 keys, and `building_age` collides with
   commercial). The appetite score the console explains is `100 * (w · t)` over
   Federato's eight factors (INTERPRETATIONS W-1), so those are served. Tenant
   weights remain visible on each tenant rule's `weight`.
   Rejected: merging all books (key collision silently overwrites a weight).

2. **`interpretations` = every rulebook's `interpretations`, concatenated in book
   order (commercial, extensions, tenant), de-duplicated by `id`.**

3. **Rulebook labels** are fixed strings in `static.ts`; `isExtension` is true
   only for `extensions`, whose label says "ours, not Federato's" (PRD 6.6).

4. **Rulebooks are read once per app via `readRulebook` and cached;** a failed
   read is not cached, so the next request retries.

5. **`GET /glossary` goes through `deps.adapter.getGlossary()`** — both adapters
   serve the GLOSSARY.pdf transcription, so no network is involved.

6. **`GET /s/:shareSlug`:** unknown slug → 404 `NOT_FOUND`; a slug whose
   submission has no stored result → 409 `NOT_SCORED`. The payload is a strict
   whitelist of `ShareDto` fields (no canonical, raw, insured name or contact);
   `decidingRule.tier` is dropped because `ShareDto` does not carry it.

7. **`GET /health` `submissionCount`** is `submissions.list({ limit: 0 }).total`
   (a `COUNT(*)`, no rows loaded).
