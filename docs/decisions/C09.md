# C09 decisions — Buildings (PRD 10 e) and Contradictions/Interpretations (PRD 10 f)

1. **No recomputation.** The rollup strip shows only `RollupView` fields, formatted with
   `@retrofit/contracts` formatters. The panel does not classify buildings as pre-1990 / post-2010
   itself (that would re-decide INTERPRETATIONS building-age boundaries); per-building age signals
   come only from the API's `flags`, rendered as labelled badges. Rejected: deriving an age band
   from `yearBuilt` in the console.
2. **Row count mismatch is surfaced, not hidden.** If `buildings.length !== rollup.buildingCount`
   (policies can hold up to 129 buildings; the API may page), a "Showing N of M" line appears.
3. **Contradiction order is display-only:** open before resolved, then HIGH > MEDIUM > LOW, stable.
   Open HIGH items carry a one-line note citing INTERPRETATIONS V-3 (REFER unless a knockout already
   decides DOES NOT FIT). Status is matched case-insensitively against `open`, per the engine's
   `'open' | 'resolved'` union.
4. **Source labels:** self_reported → Self-reported, enrichment → Enrichment, sweep → Sweep,
   answer → Broker answer. Confidence rendered as a whole percent.
5. **Interpretation citations** use `CitationQuote compact` (full quote kept in the title).
6. **Test placement:** the colocated test file is not in C09's `owns`, so it was run from the
   scratchpad and its content filed as `docs/contracts/requests/C09.md`.
