# A03 decisions — observe + relate

1. **Calls use `provider.generateJson` directly, not the `generateJson(provider, req)` wrapper.** The provider interface already reports `attempts`/`degraded`, and the wrapper (A02) was unimplemented in parallel; calling through it would make these calls untestable until A02 lands. Rejected: wrapping through `generate-json.ts`. A18 can wrap if it wants a second layer.
2. **Self-consistency order (PRD §9.3.4) is deterministic:** `runIndex 0` = capture order, `runIndex 1` = reversed. Each image is preceded by a text part `Frame index=<i>, bearing <deg>°, quality <q>`; the model returns the index, never the position. Rejected: seeded shuffle (no seed in `ObserveInput`, and reversal already maximally changes order).
3. **Zod is lenient, code sanitises.** Labels are `z.string()` and filtered against `input.vocabulary ∩ OBJECT_VOCAB`; one bad label never costs a retry of a 15-image request. `category` is overwritten from `OBJECT_CATEGORY[label]` — the model's category is ignored. `box_2d` is clamped to 0..1000, reordered to y0<=y1, x0<=x1, and dropped if not 4 numbers or zero-area. Confidence via `math.clamp01`.
4. **Unusable frames contribute nothing:** objects dropped, `ceilingVisible` forced false (so negative smoke-detector evidence can't come from a screen photo). A sent frame the model omits comes back `usable:false`, reason `frame not returned by the model`. Unsent/duplicate indices are dropped (first wins).
5. **relate:** keys outside `allowedHazardKeys` dropped; observation ids not sent dropped/deduped; a `present:true` hazard with no valid supporting id dropped (hallucination guard); `present:false` may have none (it adjusts an engine hazard down). Duplicate keys keep the highest confidence. Output ordered by `allowedHazardKeys`. No call is made when there are no observations or no allowed keys.
6. **observe** throws a non-retryable `LlmError` if image count ≠ descriptor count; empty sweep returns `{frames: []}` without a call.
7. **Live smoke** uses a tiny provider local to the test file (`@google/genai`, MODELS chain) so it does not depend on A02.
