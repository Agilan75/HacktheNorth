# F01 decisions — OAuth token source + live adapter

1. **`FEDERATO_BASE_URL` accepts the host or the full handler URL.** If the path has no `/handlers/`, `/integrations-api/handlers/federato-hack-north` is appended; `outputOnly=true` is added when absent. Rejected: requiring one exact form (a misconfigured `.env` would silently 404).
2. **Defaults** when unset: token URL `https://auth.product.federato.ai/oauth/token`, audience `https://product.federato.ai/core-api` (PRD §7.1). Missing client id/secret fails fast with code `MISSING_CREDENTIALS` and no network call.
3. **Expiry** is stamped from the moment the token request was sent (`requestedAt + expires_in*1000`, default 14400 s). Refresh when `now >= expiresAtMs - TOKEN_REFRESH_MARGIN_MS` (5 min). Concurrent `getToken()` calls share one in-flight mint; `invalidate()` bumps a generation so a stale in-flight mint never lands in the cache; failed mints are not cached.
4. **401 from the handler → invalidate + retry once.** A second 401 throws. Rejected: unbounded retry.
5. **Success = any 2xx** (the handler answers 201). Errors are thrown as a `FederatoApiError` whose own fields (`code`, `message`, `httpStatus`, `raw`) make it a structural `FederatoErrorShape`, so the planner can store the caught error directly. `Error.message` is `[CODE] message` when a code was parsed. A `[CODE]` string arriving inside a 2xx envelope is also treated as an error.
6. **`parseFederatoError`** keeps the trailing details JSON in `message` (e.g. `Unknown operator "$grt" {"operator":"$grt"}`) and tolerates a leading `Error: `.
7. **Schema action sends `{ action: "schema" }` with no payload**, exactly as API_DOCUMENTATION.pdf shows. The live map `{ Resource: { fields } }` is flattened to `SchemaDocument`: nested objects become dot-paths (`dates.effective`, `producer.broker`), `optional` → `nullable: true`, references carry `reference`, `cardinality: many` → `isArray: true`, scalar arrays keep `type: 'array'` (matches `mini-snapshot.ts`). A response that is already `{ resources: [...] }` passes through.
8. **Guidelines and glossary** are PDFs, not endpoints: `liveGuidelines` / `liveGlossary` return `readGuidelines()` / `readGlossary()` from the transcriptions. No network.
9. **Without an injected `tokenSource`**, one token source per `FederatoEnv` object is kept in a `WeakMap`, so repeated bare `liveQuery` calls share a cache. Token minting uses global `fetch` (the frozen `mintToken(env)` signature has no fetch parameter); the adapter's `fetchImpl` is used only for handler calls.
