# V07 decisions

1. **What the guideline brief contains.** The AG p2 table as written, the four PRD 6.6
   interpretations (they are published on the rule card), the T-BLANK reading, and a
   verdict/deciding-factor procedure matching INTERPRETATIONS V-1..V-5 and V-8, with the
   V-8 tie order expressed as a precedence list of factor ids. It does **not** contain the
   weights, the score formula, or any exact-boundary decision from INTERPRETATIONS §3
   (e.g. "$150M is Acceptable", "exactly 50% is Acceptable"): reading the boundary is what
   layer C tests, and PRD §12 expects disagreements to cluster there.
   Rejected: handing the model INTERPRETATIONS.md wholesale — that turns layer C into a
   re-implementation check with an unreliable implementer, not a "careful reader" check.
2. **Facts text never rounds onto a threshold.** Money and shares print with the fewest
   decimals (≤ 6) that show the value exactly, via the shared `formatMoney`/`formatPercent`.
   Unknown is printed as `unknown (not provided)`; zero stays `$0`. Unrecognised strings are
   printed JSON-quoted as given, not normalised. Boundary labels, stratum and case id are
   never in the text.
3. **Wilson.** Default 95%; z from Acklam's inverse-normal (rel. error < 1.2e-9). Zero trials
   → point 0, interval [0, 1]. Bounds are pinned to exactly 0 / 1 at p = 0 / 1.
4. **summary.json.** Top-level keys mirror `AggregateDto.verification` so A19 can pass them
   through; `propertyCasesRun = differentialCasesRun = run.completed` (layers A and B run
   on the same cases); `extractionFieldAccuracy` is `null` (not an input to `renderSummaryJson`;
   V09's CLI can overwrite it). Extra detail under non-DTO keys.
