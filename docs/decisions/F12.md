# F12 — explanation template, recommendation, mixed-case wording, narrate guard

## Recommendation mapping (PRD 7.7 names the four values, not the mapping)
- FIT -> accept.
- DOES_NOT_FIT with a flip whose verdictAfter is FIT -> review (one or two movable changes reach appetite).
- DOES_NOT_FIT with no flip -> decline.
- REFER with missing required data or an open HIGH contradiction -> investigate (the broker must supply something).
- REFER from a refer rule alone (R-AGE-REFER) -> review.
Rejected: decline for every DOES_NOT_FIT. Most of the 27 policies knock out (LIVE_DATA_FACTS), so the flip is exactly what separates "worth a conversation" from "no".

## Template shape (always 2-3 sentences)
1. Verdict + appetite score (/100) + optional rank + key numbers (TIV, quoted vs predicted premium, 5-year losses).
2. Factor sentence: the mixed-case sentence when some known factors are in and some out; otherwise in/out summary; then clauses for missing data, open HIGH conflicts, pre-1990 building ids (R-AGE-REFER), other states with shares (I-1, required by INTERPRETATIONS I-1), and the I-3 assumption when the engine surfaced it.
3. "Recommendation: <rec>, because <reason>." with the flip move and score-after when the rec is review-by-flip.
A refer-flagged factor (tier 0.6) counts as in appetite. Missing factors are neither in nor out.
Factor order in lists = the INTERPRETATIONS section 2 factor order, so the PRD example reads "In appetite on state and TIV, out on premium" (PRD wrote "TIV and state"; order was not specified, factor order is deterministic).

## Numbers
`Explanation.numbers` records every number that appears in `text`, at its displayed value (`$65.0M` -> 65000000, `60%` -> 60, `85/100` -> 85 and 100). Named keys for the key numbers; any other number in the text (the `5` of "5-year", `1990`, digits in ids) is keyed `n<i>`.

## Narrate guard
- Every template number must appear in the polished text (tolerance 1e-9 relative), after normalization ($1.2M == 1,200,000 == 1.2 million).
- No number may appear that the template lacks.
- The recommendation stem must still appear, and no other recommendation stem may appear that the template lacked.
- Any failure -> ok=false and text = template. Empty narration fails.
Rejected: allowing re-rounding (e.g. $65M for $65.4M). It lets the model change a number; the template already rounds for display.
