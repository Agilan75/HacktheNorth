# C03 decisions — DataTable, Filters, Layout, AdapterBanner

1. **Styling is inline, from `@retrofit/design` tokens (`cssVar`, `SPACE`, `RADIUS`, `MIN_TOUCH_TARGET`).**
   `base.css`/`tokens.css` belong to C02 and were placeholders; a shared class
   (e.g. `.visually-hidden`) cannot be assumed, so the sr-only style is a private
   constant in each file. Rejected: adding classes to base.css (not owned).
2. **DataTable sort cycle: none → asc → desc → none.** Nulls always last in both
   directions; ties keep incoming order (stable), so the server's rank order is the
   neutral state. Strings compare case-insensitively with numeric collation.
   Rejected: two-state toggle (no way back to server rank without reload).
3. **DataTable loading renders 5 private skeleton rows** with `aria-busy` rather than
   C02's `<Skeleton>` atom, so the table has no runtime dependency on another unit's body.
4. **Filters use native `<select>` with an "All …" sentinel (`__all__`) mapped to `null`**;
   option lists are de-duplicated and sorted. A selected value missing from options is
   still shown. A "Clear filters" button resets to the empty value. Rejected: combobox
   widgets (more a11y surface for no gain).
5. **AdapterBanner, kind omitted:** a private `HealthBanner` calls C01's
   `useApi(c => c.health(), [])`; with `kind` given, no request is made. Loading shows
   "Checking data source", error shows "Data source unknown" — it never renders nothing
   (PRD §10 "Never hidden").
6. **Layout:** skip link → `<main id="rf-main">`, header holds brand, `nav[aria-label=Primary]`
   (react-router `NavLink`, active = underline + weight + `aria-current`, not colour alone),
   and the banner slot unconditionally.
