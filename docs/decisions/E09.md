# E09 — voi (value of information over the presence mask)

The PRD gives stage 11 one line ("`m` + undetermined rules → next question +
skipped fields, each with a one-line reason") and INTERPRETATIONS.md fixes no
VOI numbers. These are the decisions E09 made.

## D1 — Expected score swing = 100 x factor weight

A missing appetite component has `t = null` and contributes 0 points (G-2). Its
tier value after an answer lies in `[0, 1]`, so the largest possible change in
`appetiteScore` is `100 x w_factor` with the W-1 weights (§2). `tiv` and
`total_premium` are therefore worth 15.0 points, `building_age`,
`construction_type`, `loss_value` and `submission_type` 10.0.

Rejected: a probability-weighted expectation over the tier distribution. It
would need a prior nobody has measured, and the field name `expectedScoreSwing`
("Largest possible change in appetite score") already says maximum, not mean.

## D2 — A factor already decided by a sibling component has swing 0

T-SPAN: `building_age` writes its tier into components 5 and 6. If the factor
outcome is already `known`, answering the other component cannot move the score,
so the swing is 0. The question is still ranked (not skipped) when it leaves
rules undetermined.

## D3 — Undetermined rules

A rule is undetermined for component `i` when it has **not** fired and one of
its `when` conditions addresses `i` with a value comparison. `exists` and
`missing` conditions are excluded: absence already determines those. Rule
conditions and question fields are resolved against both the component `key` and
its canonical `source` path, with `key` winning a collision (rules address
components by key, PRD 6.4).

Rejected: a full three-valued re-evaluation of every rule. That duplicates E06
and needs the canonical submission, which stage 11 is not given.

## D4 — Ranking order

`expectedScoreSwing` desc → undetermined-rule count desc → required components
before optional → component index asc → question id asc. Fully deterministic
with no clock and no randomness.

## D5 — A question worth nothing is skipped, not ranked

Zero swing **and** zero undetermined rules → `SkippedField`. That is the whole
point of a VOI stage: it must be able to say "not worth asking".

## D6 — Knockouts do not suppress questions

An account with a knockout is `DOES_NOT_FIT` (V-1) whatever else is answered,
but completeness and the flip still need the missing fields, so E09 keeps
ranking them. Rejected: returning `nextQuestion = null` on knockout — it would
make the mobile flow dead-end before the flip can be computed.

## D7 — `askedCount` counts distinct ids

`askedQuestionIds` may repeat if a caller re-posts an answer; the counter is the
size of the id set.
