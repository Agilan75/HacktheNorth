# C11 decisions — Actions, ReplyBox, AttachedSweep panels

1. **Rank movement is shown as "up N / down N"** computed as `beforeRank - afterRank` in the log. This is a
   display difference of two numbers the API returned, not a recomputed score or rank. Rejected: showing only
   "5 → 2" (the PRD asks for "the rank movement each reply caused").
2. **Thresholds used only for labels are mirrored locally** (like Pricing.tsx does): `MIN_EXTRACTION_CONFIDENCE
   = 0.8`, `MIN_COVERAGE_PCT = 75`, observation confirm-below `0.6`. `@retrofit/engine` is not a console dependency.
   Acceptance of an extracted field is decided by the server's `accepted` flag, never by the local 0.8.
3. **Approve button renders only when `status === 'draft'`** (PRD 7.6: requests are saved as drafts, the underwriter
   approves). Other statuses show a status badge only.
4. **`SweepView.coverage` is read as 0..100** (engine `CoverageResult.coveragePct`), formatted with `from: 'percent'`.
5. ReplyBox clears the textarea / file input only after the submit handler resolves; a rejection is shown as
   `role="alert"` and the text is kept so the user can retry.
