# D01 decisions

1. **Muted (#7C8073) on Paper is 3.81:1 — AA-large only.** `contrastMatrix()` reports it honestly (`passesAA: false`). Rule: `muted` text only at 22px+ or decorative; small secondary text uses `mutedDeep` (5.82:1). Rejected: changing the token (tokens.ts is frozen, PRD 13 fixes the value).
2. **Paper on Red (FIT pill) is 4.56:1** — passes AA by a hair. If the placeholder red is swapped for Intact's red, the contrast test will catch a regression.
3. **Contrast pairs** = ink/mutedDeep/muted/red/redDeep on Paper, ink/mutedDeep on Muted tint, ink/redDeep on Red tint, plus each verdict pill from VERDICT_STYLES (transparent fill evaluated on Paper).
4. **Dynamic type** clamps the OS font scale to [0.8, 3.2] (iOS xSmall to AX5); non-finite or <=0 → 1. fontSize rounds to integer; lineHeight is ceil'd to the 4pt grid and never below fontSize.
5. **Families/weights:** display/title/heading = Fraunces 600; body/small = Inter 400; micro = Inter 500. Verdict pill text = Fraunces 600 at the `small` step.
6. **Pills:** radius 999, 1px border in the verdict border colour, padding 12h/4v. Not given a 44pt min height — pills are labels; pressables wrap them with `touchTargetStyle()`.
7. **touchTargetStyle(n)** returns max(44, n); it never goes below 44.
8. **renderTokenStylesheet** = banner comment + `cssVariableBlock(selector)`; an empty banner emits no comment; `*/` in a banner is neutralised. Writing `apps/console/src/styles/tokens.css` is not D01's (C02 owns it).
