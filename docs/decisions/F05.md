# F05 decisions — MockFederatoAdapter, createAdapter, adapter banner

1. **Live requires `FEDERATO_BASE_URL` + `FEDERATO_CLIENT_ID` + `FEDERATO_CLIENT_SECRET`** (non-blank). Token URL and
   audience have defaults in `auth.ts`, so their absence does not force the mock. Rejected: requiring all five
   (would silently drop to the snapshot on a config that actually works).
2. **Banner wording** is `*** FEDERATO: LIVE API (<host>) ***` or
   `*** FEDERATO: SNAPSHOT (MockFederatoAdapter) - NOT the live API - <why> ***`. Only the base URL host is printed —
   never a path, query string or credential. `<why>` names the missing env vars. `adapterBanner` returns the string;
   `apps/api/src/banners.ts` prints it. `createAdapter` does not print, to avoid a double banner.
3. **Snapshot loading is eager**: `createAdapter` calls `loadSnapshot()` (F02) at construction when no snapshot is
   supplied, so a missing snapshot fails loudly at startup rather than on the first query.
4. **Results are `structuredClone`d**, so no caller can mutate the snapshot through a result.
5. **Unknown resource** rejects with `[VALIDATION_ERROR] Unknown resource "<name>".` (the live `[CODE]` string style).
   All adapter methods reject rather than throw synchronously.
6. `getSchema` returns `options.schema ?? snapshot.schema`; guidelines/glossary default to the PDF transcriptions
   (`readGuidelines` / `readGlossary`), same as the live adapter.
