# A01 decisions — DB client, migrate, repos

| # | Decision | Reason | Rejected |
|---|---|---|---|
| A01-1 | The `node:sqlite` fallback wraps `DatabaseSync` in the slice of the `better-sqlite3` API Drizzle's better-sqlite3 session calls (`prepare`/`run`/`all`/`get`/`raw`, `transaction`), and feeds it to `drizzle-orm/better-sqlite3`. Driver name `node-sqlite-proxy`. Exported as `openNodeSqlite` so it is tested on a machine where better-sqlite3 loads. | `drizzle-orm/sqlite-proxy` is async-typed; the frozen `Db` is `'sync'`. The shim keeps one Drizzle driver and one sync surface. | `sqlite-proxy` + cast (every `.all()` would return a Promise at runtime). |
| A01-2 | `createDb` falls back only when the error looks like a native-binding load failure; any other error (bad path, missing read-only file) is rethrown. File DBs get their parent dir created and `journal_mode=WAL`; all get `busy_timeout=5000`. | A bad path should not silently switch drivers. | Fallback on any error. |
| A01-3 | `upsertByExternalId` on conflict keeps `id`, `createdAt`, and never clears an existing `shareSlug` or `rank` by passing null/undefined; every other provided column is overwritten. | Re-ingest must not break a minted public link or the queue position before the next rank pass. | Replace the whole row. |
| A01-4 | `enrichments.upsert` is keyed on (submissionId, source) and keeps the first row's id. | Matches the unique index; one card per source. | Delete + insert. |
| A01-5 | Submission order everywhere (`list`, `all`): rank ascending, unranked last, ties by externalId. Actions `list`: newest first (`createdAt` desc, `id` desc). Sweeps by submission: creation order. Enrichments: by source. | Queue is rank-ordered; outbox/log reads top-down. Deterministic ties. | Insertion order. |
| A01-6 | `update(id, patch)` drops `undefined` keys and `id`; an empty patch returns the existing row; an unknown id throws. Timestamps are never set by the repo — callers pass `updatedAt` from `Deps.clock`. | No clock may be read outside `Deps.clock`. | Repo stamping `updatedAt` with `Date.now()`. |
