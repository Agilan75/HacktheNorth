# A09 decisions — image metrics, quality gate, crops

| # | Decision | Reason | Rejected |
|---|---|---|---|
| A09-1 | Blur, brightness and clipping are measured on an EXIF-oriented, alpha-flattened grayscale copy downscaled to fit 512px (never enlarged). `width`/`height` are the full oriented dimensions. Laplacian is the 4-neighbour kernel over interior pixels, 0..255 scale. | Laplacian variance scales with resolution; a fixed analysis size makes one threshold work for every phone. | Full-resolution analysis (threshold drifts with camera). |
| A09-2 | pHash = classic DCT hash: 32x32 fill-resized grayscale, low 8x8 DCT block, bit = coefficient > median of the 63 AC terms, row-major, MSB first, 16 lowercase hex. | Standard, robust to re-encode and resize. | aHash/dHash (weaker under exposure change). |
| A09-3 | Quality = the minimum of four 0..1 component scores (worst defect decides): sharpness `clamp(lapVar/100)`; exposure 1 in [0.2,0.8], linear to 0 at 0.05 / 0.95; clipping 1 at ≤0.05, linear to 0 at 0.30; resolution (short side) 1 at ≥480px, linear to 0 at 160px. Rounded to 3 dp. Pass = quality ≥ 0.4 (`QUALITY_THRESHOLD`) and not a duplicate. | Explainable: the reason names the single deciding defect. | Weighted product (four mild defects compound into a drop nobody can explain). |
| A09-4 | Duplicate = pHash Hamming distance ≤ 5 to the previous frame. A duplicate fails even at quality 1. | Common pHash near-dup cut-off. | Distance ≤ 10 (drops genuinely panned frames in a slow sweep). |
| A09-5 | `reason` is a machine code: `blur`, `too_dark`, `too_bright`, `clipped`, `low_resolution`, `duplicate`, or null on pass. A low-quality frame reports its quality reason even if it is also a duplicate. | UI/re-sweep copy maps codes to wording; code must not generate prose. | Free-text reasons. |
| A09-6 | `cropToBox` auto-orients first, normalises swapped corners, clamps box values to 0..1000, pads by `padding` × box size per side, clamps to the frame, guarantees ≥1px, and always returns JPEG (q85, alpha flattened on white). Non-finite box values throw. | Gemini's box_2d refers to the upright image; one output format for the detail screen. | Preserving the input format. |
