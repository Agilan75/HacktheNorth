# V02 decisions — seeded PRNG and vector generator

| # | Decision | Reason | Rejected |
|---|---|---|---|
| V02-1 | PRNG is sfc32, state expanded from the seed by splitmix32, first 12 outputs discarded. The seed is folded to uint32 keeping its high 32 bits and fractional part (`2**32+1` ≠ `1`). `deriveSeed` = FNV-1a(label) mixed into the folded seed, finalised with murmur3 fmix32. | Pure 32-bit integer maths → bit-identical in every worker and machine; fast enough for 10M cases. | mulberry32 (weaker, 32-bit state); `Math.random` (not seedable). |
| V02-2 | `chance(p)` always draws exactly one value, whatever `p`. | Stream position never depends on a probability, so edits to one rate do not reshuffle unrelated draws within a branch. | Short-circuiting p=0/1. |
| V02-3 | Indices 0..11 of every seed are INTERPRETATIONS §8 B1..B12 verbatim (`generateCase(seed, i)` ignores the seed there). Every later index draws from its own child stream `createPrng(deriveSeed(seed, 'vec:' + index))`. | §8 says "copy these into the generator"; per-index streams make any case replayable from (seed, index) regardless of chunking. | One sequential stream per chunk (replay would depend on chunk boundaries). |
| V02-4 | `boundaryCatalogue()` lists only vector (NaiveInput) numeric components: TIV 50M/100M/150M, premium 50K/75K/100K/175K, loss 100K, pctTivPre1990 **0** and 0.5, pctTivPost2010 0.5, pctTivAcceptableConstruction 0.5. `pctTivPre1990 = 0` is the R-AGE-REFER edge. `yearBuilt` 1990/2010 are building-level and belong to the submission generator (V03). | The vector generator cannot sample a component it does not produce; a coverage check over the catalogue must be satisfiable by vector cases. | Including `yearBuilt` entries. |
| V02-5 | "Just under/over" = one ulp, one cent (thresholds ≥ 1000), or a relative step in {1e-12, 1e-9, 1e-6, 1e-4, 1e-3}·max(|t|,1). `far_*` = 0.1–1× (under) / 0.1–2× (over) of max(|t|,1) away. `boundaries` labels are recomputed from the final value against the nearest threshold (within 1e-2 relative = under/over), so they are always truthful; components drawn from realistic distributions are labelled `random`; missing components are omitted. | Labels are what V03/V05 filter on, so they must match the value after clamping/masking. | Recording the requested position. |
| V02-6 | Ordinary cases clamp shares to [0,1] and money to ≥ 0. Out-of-range values appear only in the ~10% "extreme" cases, drawn from fixed hostile lists (0, -0, -1, -150M, 1e18, ±MAX_VALUE, MIN_VALUE, EPSILON, shares -1e-9/-0.5/1.0000001/2, empty/padded/lower-case strings). No NaN/Infinity is ever emitted: non-finite arrives as `null` (G-1). | Keeps boundary cases on the domain while still feeding NAIVE_SPEC §4.1's hostile values; NaN would not survive JSON disagreement logs. | Emitting NaN/Infinity literally. |
| V02-7 | building_age's two components are always jointly null or jointly known (V-6), including in extreme cases. `anyBuildingPre1990` is `true` whenever pctTivPre1990 > 0; when the share is exactly 0 it is `true` 25% of the time (a pre-1990 building with unknown TIV — the R-AGE-REFER zero-share refer path); when ages are missing it is null/false/true uniformly. pre + post ≤ 1 is enforced only when post is drawn realistically; two boundary-pinned shares may sum to 1 + ulp. | Consistent with the rollup the engine would produce, while not blocking pre/post boundary combinations. | Forcing pre + post ≤ 1 always (would remove pre=0.5+ulp with post=0.5). |
| V02-8 | Presence mask: per-case missing rate from {0,0,0,0.05,0.15,0.4}, applied independently per factor; 1% of cases are all-missing. Open HIGH contradiction on 10%. | Majority fully known (differential on arithmetic), with enough masking to test completeness and V-8. | A single fixed rate. |
