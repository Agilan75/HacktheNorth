# E15 — decisions (rating fit library, priors, rating:fit CLI, rating/tenant.json)

## D-1 — fit rows are buildings; the policy premium is spread by TIV share
PRD 6.7 prices Σ over buildings, but `technical_premium` exists per policy. The
CLI emits one `FitRow` per building (known TIV and year) with
`technicalPremium = policyTechnical × buildingTiv ÷ policyTiv`. The loss band is
policy-level and so is shared by the policy's rows. Rejected: one row per policy
with TIV-weighted "dominant" classes — it throws away the per-building mix.

## D-2 — reported error is per POLICY, measured through `priceCommercial`
`fitMonotonic` returns a row-level error. The CLI re-prices each policy with the
real runtime `priceCommercial` on the fitted table and writes THAT error
(n = policies, ~27) into `rating/commercial.json`, so the number on screen is
the engine's own error. `mape` is a fraction (0.12 = 12%), matching price.test.

## D-3 — solver: block coordinate descent in log space, ridge toward priors, PAVA per block
Each family's block is a separable weighted quadratic, so its exact constrained
minimizer is the weighted isotonic regression (util/math `poolAdjacentViolators`,
non-increasing worst-to-best) of the per-level minimizers. Every level is pulled
toward its log prior with a pseudo-weight of 2 average rows (row weights = TIV
share, normalized to mean 1). A level with no rows sits exactly on its prior —
this is how "too few observations" is handled, smoothly rather than by a cutoff.
The intercept (baseRate) is unpenalized. The ridge also makes the base/level
split identifiable. Rejected: hard min-count cutoffs; unregularized fit
(27 policies × 5 families is under-determined for several levels).

## D-4 — unknown inputs are neutral (factor 1), same as runtime pricing
Construction class not in the order, null protection class, null sprinkler, or
non-finite five-year loss (the CLI passes NaN when rollup has none) contribute
factor 1, exactly as `priceCommercial` does.

## D-5 — band structure and orderings
- construction worst→best: Wood Frame, Frame, Joisted Masonry, Non-Combustible,
  Steel Frame, Masonry Non-Combustible, Modified Fire Resistive, Fire Resistive
  (ISO classes 1→6; the eight live values from LIVE_DATA_FACTS, data spelling).
- age (yearBuilt, inclusive upTo): ≤1949, ≤1969, ≤1989 (the pre-1990 line), ≤2009, 2010+.
- protection class: 1–3, 4–6, 7–8, 9, 10.
- five-year loss: 0, ≤25K, ≤100K (appetite line), ≤250K, above.
Band bounds live privately in `least-squares.ts`; the keys are ordered by
`commercialPriors()`; the test asserts they agree via the empty-rows table.

## D-6 — no clock in the engine
`fittedAt` is written only when `--fitted-at <iso>` is passed. No `Date.now()`.

## D-7 — rating/tenant.json values
No tenant loss data exists (PRD 6.7 "estimate"), so values are judgement:
base $14/month; contents bands ≤10K 0.85 … >50K 1.70; building age ≤1939 1.30 …
2010+ 0.92; a surcharge for each of the 10 hazard components of
`vectors/tenant.json` (keys = component key minus `hazard`, lower-camel, as
`priceTenant` looks them up); smoke detector present 0.92 / absent 1.15; term
keys "4".."12", 1.12 → 1.00 (short terms carry a per-month loading).
