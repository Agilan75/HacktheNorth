# F03 — decisions

Unit F03: mock `where` / `filter` matching (`packages/federato/src/mock/where.ts`).
QUERY_REQUEST_BODY.pdf and LIVE_DATA_FACTS.md were obeyed; below is only what they leave open.

## D1 — A literal value is strict deep equality, never Mongo array-membership
`{ hazard_tags: 'hail' }` does not match `['hail','wildfire']`; the PDF defines a literal as `===` / deep equality. Membership is `$contains` or `$in`.
Rejected: Mongo's implicit "scalar matches any array element" — undocumented for this API and would hide the array pitfall.

## D2 — `null` is a value, not "missing"
`{ f: null }` and `$in: [null]` match only a stored `null`. `$exists: true` is true for `null`. `$ne` and `$nin` match a missing field.
Rejected: Mongo's null-matches-missing; the types file states null is a real value.

## D3 — Dot-paths stop at arrays, including numeric indices
`a.0.b` returns undefined. Only `$elemMatch` crosses an array. Reproduces the measured 0-vs-47 CA case.

## D4 — Comparisons need same-typed scalars
`$gt/$gte/$lt/$lte` compare number-number or string-string (ISO dates compare lexically). Anything else, including null/missing, is false.

## D5 — `$in` / `$nin` on an array field test any element
Per the PDF's "Scalars/arrays" row. `$nin` is the exact negation of `$in`.

## D6 — `$contains` is case-sensitive
Substring on strings (numbers/booleans stringified), deep-equal membership on arrays; null/missing never contain.

## D7 — `$elemMatch` accepts an operator bag for scalar arrays
`{ $elemMatch: { $gt: 5 } }` applies the bag to each element; otherwise each element is matched as a record-shaped clause. Non-arrays and empty arrays are false.

## D8 — Combinators work at any depth; empty edge cases
`$and`/`$or`/`$not` are allowed inside a field node (so `{ premium: { $not: { $gt: 1 } } }` works). `$and: []` is true, `$or: []` is false, `{}` matches everything.

## D9 — Unknown `$` keys throw
The mock throws `unsupported operator $x` rather than silently matching, so a planner bug surfaces in tests instead of producing a quietly wrong result.
