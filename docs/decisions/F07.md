# F07 decisions: synonym table + resource graph

1. **Canonical path spelling.** Synonym rows use the engine discover stage's spelling (`buildings[].tiv`, `locations[].state`, `history[].reserves`, `coverage.lines[].limit`). `lookupSynonym` also accepts `buildings[0].x`, `buildings.B1.x` (merge-style id key), `buildings.x`, and any casing or whitespace. Rejected: indexed-only keys, because F08 gets paths from both the vector spec and the rulebook.
2. **`resource` is the resource that owns the leaf.** The graph search supplies the hops from the root. `schemaPath` is a leaf or a nested-object path (`dates.effective`). It crosses a reference in exactly one row: `insured.headquartersState` becomes `Insured` + `hq.state`, so it can't collide with `locations[].state` on `Location.state`. Rejected: `Location.state` for the HQ state, which makes `reverseSynonym('Location','state')` ambiguous.
3. **Multiple rows per canonical path.** Rows are ordered by preference. Lookup returns the highest confidence, and on a tie the earliest row. For the submission identity fields (externalId, lineOfBusiness, status, receivedDate, requestedLimit), `Submission` comes first because triage is Submission-rooted. For effectiveDate, `Policy` wins. `history[].reserves` has two rows (reserve_indemnity and reserve_expense) because INTERPRETATIONS defines reserves as their sum. F08 and normalize must read both.
4. **No rows** for `rollup.*` (derived), `hazards.*` (swept), `floodZone` / `fireStationDistanceKm` (enrichment), or tenant exposure fields. These have no Federato field.
5. **Graph tie-break follows the frozen doc comment:** fewest hops, then fewest `many` hops, then dotPath, then target name. **Consequence:** `shortestPath(Policy, Building)` is `insured.hq.buildings`, not `exposure_units.location.buildings`, and `shortestPath(Policy, Location)` is `insured.hq`. That is correct by the stated rule, but those buildings are the insured's HQ buildings, not the policy's risk locations. F08 and F09 must use `DeepPlan`'s fixed `exposure_units.location.buildings`, or pick from `pathsFrom()`. They must not trust `shortestPath` for property risk data. `pathsFrom(Policy)` lists both, with `insured.hq.buildings` first.
6. **`pathsFrom` defaults to maxHops = 3** (the depth of the deep pass). Paths are simple (no resource is visited twice), and every prefix counts as a path.
7. **`expandForPath`** splits nested-object reference fields (`producer.broker` becomes `{ producer: { broker: true } }`), matching the ExpandClause equivalence in types.ts. An empty path returns `{}`.
8. **`buildResourceGraph`** ignores resource names outside the twelve-member `FederatoResource` union. Its output is sorted, so it is deterministic.
