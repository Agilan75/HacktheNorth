# A02 decisions — Gemini provider + generateJson

1. **REST via injectable `fetch`, not the `@google/genai` SDK.** PRD §9.1 names the SDK, but the
   frozen `GeminiProviderOptions` carries `fetchImpl`, and the prototype is REST. REST lets the
   offline tests drive every branch (fall-through, MAX_TOKENS, blocks, bad JSON) without network.
   Rejected: SDK (untestable offline without mocking its internals). Swapping later is one file.
2. **API key in the `x-goog-api-key` header**, never the `?key=` query string (prototype), so it
   cannot leak into a URL log line.
3. **Layering.** `provider.generateJson` = one logical attempt: walks `MODELS` in order, falls
   through on `RETRYABLE_STATUSES` (408/429/500/502/503/504 — the frozen superset of the PRD's
   429/500/503), cycles the chain `MAX_ROUNDS = 2` times with `ROUND_BACKOFF_MS = 2500`, parses the
   envelope (thought parts dropped), `sanitize`s, zod-validates. `generateJson(provider, req)` adds
   the one retry and the degrade, so the fake provider gets the identical policy. Call units must
   use `generateJson(provider, req)`, not `provider.generateJson` directly.
4. **Retryable** (costs the one retry): overload after the chain, network error, non-JSON envelope,
   unparseable model JSON, zod failure, empty answer, `MAX_TOKENS`. A `MAX_TOKENS` retry doubles
   `maxOutputTokens` (base 8192 if unset, ceiling 65536). **Not retryable**: unconfigured,
   non-retryable 4xx, prompt block / SAFETY finish, abort.
5. **Degrade** after the retry fails: return the schema's *safe empty answer* with
   `degraded: true` only if every required field is an array (→ `[]`) or nullable (→ `null`) and
   the caller's zod accepts it (observe/relate/schema-assist/extract-reply). If a string, number,
   boolean or enum would have to be invented (narrate, draft-request, verify-fix, second-opinion)
   the last `LlmError` is thrown and the call unit uses its own deterministic fallback — inventing
   `stillPresent: false` or a verdict would be the LLM layer deciding by omission.
6. **sanitize** generalises the prototype: every `confidence` key clamped via `clamp01`, other
   numbers clamped to the schema's declared `minimum`/`maximum`. Shape errors are not repaired.
7. Default `maxOutputTokens` 8192 (thinking spends 89–263 tokens on a trivial prompt), temperature 0.2.
8. Extra exports added to `gemini.ts` (additive, not re-exported by the barrel): `MAX_ROUNDS`,
   `ROUND_BACKOFF_MS`, `DEFAULT_MAX_OUTPUT_TOKENS`, `DEFAULT_TEMPERATURE`, `VisionError`, `clamp01`,
   `sanitize`, `buildRequestBody`, `parseEnvelope`, `readUsage`, `toFinishReason`; and
   `safeEmptyAnswer` in `generate-json.ts`.
9. Offline tests live in `gemini.live.test.ts` (the only test path A02 owns) — see
   `docs/contracts/requests/A02.md`.
