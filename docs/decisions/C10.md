# C10 decisions (Flip, Vector, Enrichment panels)

1. **No own `<Card>` wrapper.** `SubmissionPage.tsx` (C05) already wraps every panel body in a `Card` titled with the PRD 10 letter. Rendering a second Card would duplicate the heading. The three panels render a plain `div.rf-panel`; Enrichment card titles are `h3`. Rejected: matching Pricing/ScoreBreakdown, which render their own Card and so nest.
2. **Vector tier column for non-appetite components (9, 10) reads "Not scored"**, not the tier number, because PRD 6.4 says components 9–10 never enter the appetite score. Knockout badge per G-3 (known appetite component, tier 0) is a label, not a recomputed number.
3. **Raw formatting keyed by component key** (USD for totalTiv/quotedPremium/fiveYearLoss, percent for `pct*`, 0/1 flags, state tier 0/1/2 with label). The exact raw value is always in the cell's `title` attribute so the full-precision number stays traceable (e.g. 150000000.01).
4. **Flip shows no premium delta.** The house rule forbids panels recomputing premium; before and after are shown side by side, both from the DTO.
5. **Flip move endpoints** print money with 2 decimals when non-integer so the F-5 "smallest step past the boundary" is visible ($150,000,000.01 → $150,000,000).
6. Formatter helpers are private per file (small duplication between Flip and Vector) per HELPERS.md rule 7; no new shared helper.
