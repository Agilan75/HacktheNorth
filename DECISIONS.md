| # | Decision | Why | Rejected alternative |

| W0-2.1 | **The four factors with a blank Target column (submission type, line of business, construction type, loss value) score tier value 1, not 0.6, when Acceptable is met.** | Acceptable is the best outcome those rows allow. Capping them at 0.6 makes a score of 100 unreachable and silently reweights the book. Pinned as T-BLANK in `docs/contracts/INTERPRETATIONS.md`. | Scoring 0.6 and capping the book at 84. |
| W0-2.2 | **Appetite factor weights: 0.10 / 0.15 / 0.15 / 0.15 / 0.15 / 0.10 / 0.10 / 0.10**, summing to exactly 1. The 0.15 group is the four factors that can reach Target. | The PDF states no weights and the PRD leaves them open. | W0-2.3 | **Every threshold boundary resolves to the friendlier tier**: $150M TIV, $50K and $175K premium, $100K loss, 50% construction and 50% pre-1990 TIV share are all Acceptable, not Not-Acceptable. The $50M/$100M and $75K/$100K target bands are inclusive at both ends. | The PDF's "Up to / Over / Under / >50%" wording leaves each exact boundary undefined, and the 10M differential test samples exactly there. Strict "over/under" readings are the plain-English ones. | Leaving the boundary to each implementation, which guarantees ten million false disagreements. |
| W0-2.4 | **1990 and 2010 belong to the newer side**: `pre1990 ⇔ yearBuilt < 1990`, `post2010 ⇔ yearBuilt >= 2010`. | Closes the gap the PDF leaves between "newer than 1990" and "older than 1990" without inventing a third class, and matches the vector component names. | Strict `> 1990` / `> 2010`, which leaves both cutoff years unclassified. |
| W0-2.5 | **REFER never lowers the appetite score.** A `refer` tier keeps the factor at its Acceptable value (0.6) and only raises the verdict flag. | Otherwise "any building pre-1990" would double-penalise against ">50% of TIV pre-1990", and two identical books would score differently. | Giving `refer` its own tier value between 0 and 0.6. |
| W0-2.6 | **Immovable flip components are 0, 1, 2, 5, 6, 8 and 10** of the commercial vector — PRD 6.4 names state and building age; Retrofit adds submission type, line of business, five-year losses and public protection class. Nobody can un-file a claim or re-rate their fire district. | The PRD's literal two (state, building age), which would let the engine propose "become new business". |
| W0-2.7 | **Missing appetite components contribute zero points and do not renormalize the remaining weights**, and can never set a knockout. | PRD 6.5 says a missing component is never imputed. Renormalizing would let a submission raise its score by hiding data. | Renormalizing `w` over known components. |
| W0-2.8 | **Zero claims means `fiveYearLoss = 0` and known**, provided the claims list was fetched at all; an unfetched claims list is missing. | A clean account is clean, not incomplete. | W0-2.9 | **Primary-state ties break alphabetically by state code**, and peer-distance ties break by ascending id. | Determinism is a stated invariant; record order is not stable across adapters. | First-seen order. |
| W0-2.10 | **`log` scaling is `ln(max(x, 1))`** and a degenerate min-max range returns 0 for every input. | The engine must be total: `ln(0)` is `-Infinity` and a single-account book has `min == max`. | Guarding at each call site, which is where a second implementation diverges. |
| W0-2.11 | **The engine stays zero-I/O: `data.ts` exposes pure `parse*` functions that every stage uses, plus `read*` loaders that no stage calls.** | PRD 5 says `packages/engine` has zero I/O, but the task asks for typed loaders. Splitting keeps both true. | Stages reading JSON off disk. |
| W0-2.12 | **`data.ts` (the loaders) is assigned to Run 1 unit E13**, which already owns `rules/commercial.json` and its schema test. | The loaders and the first file they load are tested together; nobody else needed them earlier. | Assigning them to E01, which owns no data file. |
| W0-2.13 | **Tenant vector: 14 components** — ten 0/1 hazards, smoke-detector count, year built, contents limit and term. Building age is the only immovable one. | PRD 6.4 names the shape but not the hazard list; these ten are the ones the 21-label object vocabulary and the pair rules can actually produce. | A component per vocabulary label, which would give 21 mostly-empty components. |
